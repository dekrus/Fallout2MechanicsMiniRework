## Последняя версия 2.0.4.2
- Добавлен скрипт, предотвращающий анимацию получения урона для существ в силовой броне (НПЦ и игрок), когда полученный урон равен 0. При попадании проигрывается звук удара о металл.
### Regen Mod
- Исправлено отображение тегов "Ожог" и "Исцеление" при прямом управлением НПЦ.
- Исправлено применение эффекта "Ожог" к атакующему при самоуроне во время использования альтернативных атак.
- Эффект "Ожог" больше не применяется, когда RegenMod отключён.
- Исправлен возможный баг с постоянным изменением статов из-за некорректной очистки эффекта "Ожог".
### Secondary Attack Mod
- Добавлена совместимость с формулой урона EcCo 1.0.0.
- Исправлено некорректное состояние, позволявшее переключаться в режим прицельной стрельбы с трейтом "Стрельба на вскидку", когда альтернативная атака невозможна.
- Исправлена невозможность выполнения прицельных атак в ближнем бою для игрока с трейтом "Стрельба на вскидку", когда "FastShotFix" включён в ddraw.ini.
- Исправлено отсутствие самоурона при попадании в область плазменного взрыва во время атаки по декорациям (двери, стены).
### Sneak Detection Mod
- Незначительная оптимизация для повышения производительности.
- Для sfall 5 исправлен вызов небезопасной функции, когда SneakRework отключён.
### Traits Plus
- Исправлена ошибка деления на ноль, когда трейт "Камикадзе" отключён.
- Добавлена проверка изменений трейтов при взятии перка "Мутация" и последующей отмене реального выбора этого перка.
- Исправлено неверное количество рангов перка "Быстрое восстановление" при "Fast_Metabolism=2".
- Для трейта "Чувствительность к химии": если Нюка-Кола не даёт эффектов сразу при употреблении, то она теперь повышает уровень радиации на 1 (в дополнение к лечению 1 ХП), чтобы облегчить набор нужного количества доз для перка.
### Miss Mod
- Добавлены опции для настройки множителей шанса выбивания оружия у вражеских НПЦ.
- Добавлена проверка критического флага "выбить оружие" (DAM_DROP). Когда он установлен в "COMBATDAMAGE_HOOK" другими модами или добавлен в крит-таблицы рук, оружие из соответствующей руки выбивается независимо от шанса.
- Добавлена опция, позволяющая выбивать любой предмет из рук, а не только оружие.
- Оружие теперь должно выпадать прямо во время анимации получения урона, а не после неё.

## Версия 2.0.4.1
### Secondary Attack Mod
- Исправлен баг, из-за которого альтернативные атаки у персонажей с особенностью "Стрельба на вскидку" вообще не работали, если `AimedBurstSecondaryAttackMod` был отключён, даже когда `AllowFastShot` был включён.
- Исправлены массивы PID'ов для альт. атаки дробовиков и прицельной очереди (дополнительные и отключаемые списки оружия).
- Исправлен вылет игры при `PistolForcedActivation` больше 1.
- Стоимость ОД альт. атаки для **пистолетов (Двойной выстрел)** и **дробовиков (Отбрасывание)** теперь всегда **+1 ОД** (как у обычного прицельного выстрела) для персонажей с трейтом **Fast Shot**.
- Добавлена отдельная .ini-переменная для множителя требований к Силе в формуле штрафа точности Двойного выстрелы.
- Добавлена .ini-опция для включения старой анимации плазменного взрыва.
- Восстановлена совместимость **дробовиков (Отбрасывание)** с формулой урона EcCo.
- Добавлена .ini-опция для настройки шанса сбить с ног у **дробовиков (Отбрасывание)**.
### Regen Mod
- Сообщение "Скорость восстановления достигла максимального значения" теперь срабатывает только при повышении, а не когда уже на максимуме.
- Исправлено применение эффекта ожога к Игроку и НПЦ от урона огнем, энергией и взрывами.
- Исправлена проблема со Sfall5, из-за которой выпадающее меню действий по правой кнопке могло зависнуть на экране и не исчезать до перезапуска игры.
### Traits Plus
- Исправлен баг, когда `Fast_Metabolism = 0` не отключал новый эффект трейта, а только возвращал его описание к оригинальному.
- Добавлена новая .ini-опция для отключения эффекта пассивной регенерации Быстрого Метаболизма.
- Немного переформулированы описания трейтов на английском, чтобы полностью помещаться в окне описания для sfall 5+.
- Повышено требование к уровню Игрока для второго(2) уровня перка "Быстрое восстановление" с 3-го до 9-го.
- Повышено требование к уровню Игрока для первого уровня перка "Быстрое восстановление" с 3-го до 6-го для персонажей с особенностью "Быстрый Метаболизм", когда включён `fast_metabolism_no_passive_regen`.
- Настройки скидки ОД у Камикадзе (шаги за -1 ОД, штраф к точности, затрагиваемые действия) теперь настраиваются через .ini.
- Перезарядка оружия теперь всегда сбрасывает бонус ОД за движение от Камикадзе.
- Сообщения о критических попаданиях при прицельной очереди теперь показывают часть тела, куда попало больше всего пуль.
- Исправлена проблема, из-за которой бонусные перки от препаратов не выдавались при `Chem_Reliant=2`.
### Medical Tools
- Докторские сумки и аптечки больше не лечат роботов.
- Инструменты и Суперемнабор теперь можно использовать на роботах для восстановления ХП и починки конечностей. Инструменты для ремонта не имеют кулдауна, не расходуются и не ломаются, могут использоваться в бою при достаточном навыке Ремонта, но не дают опыта и могут повредить робота при провале проверки навыка. (Инструменты для ремонта можно отключить через .ini)
- Только ремонтные роботы (Mr. Handy) могут ремонтировать других роботов и им для этого не требуются инструменты.
- НПЦ (враги и компаньоны, кроме роботов) теперь могут использовать докторские сумки и аптечки в бою для лечения союзников.
- НПЦ (враги и компаньоны) могут использовать докторские сумки и аптечки для лечения себя вне боя. По умолчанию компаньоны не лечат себя вне боя (можно включить через .ini).
- Бонусы к навыкам от докторских сумок, сумок парамедика и наборов инструментов теперь учитываются при расчёте стоимости ОД.
